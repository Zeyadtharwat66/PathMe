# PathMe – Course Reservation Platform

A production-ready course reservation platform developed as a freelance project, providing students and parents with a seamless way to explore courses and manage course enrollments.

## About the Project

PathMe is an educational platform designed to simplify course discovery and enrollment. The backend provides secure RESTful APIs, course management, authentication, enrollment processing, and automated email notifications.

**Project Type:** Freelance Project  
**Role:** Backend Developer  
**Status:** Live in Production

## Key Features

- **Authentication & Authorization:** Secure JWT-based authentication, role-based access control, and Google OAuth 2.0 integration.
- **Course Management:** Course creation, updating, deletion, categories, and content management.
- **Enrollment System:** Course reservation and enrollment management for students and parents.
- **Advanced Search:** Filtering, searching, and pagination.
- **Email Notifications:** Automated reservation emails and password recovery.
- **Image Management:** Image upload and storage.
- **Performance Optimization:** API caching and efficient database access.
- **User Management:** Profile management and password management.
- **Security:** Input validation, exception handling, and secure API endpoints.
- **Production Deployment:** Configured and deployed the backend application to a production environment.

## Architecture

The backend follows a layered architecture to maintain separation of concerns and improve maintainability.

- **Controller Layer:** Handles HTTP requests and API responses.
- **Service Layer:** Contains business logic.
- **Repository Layer:** Handles database operations.
- **Entity Layer:** Defines database models.
- **DTO Layer:** Manages request and response data.
- **Security Layer:** Handles authentication and authorization.
